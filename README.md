DragonFixes is a mod for Pathfinder: Wrath of the Righteous that fixes several bugs

Requires [ModMenu](https://github.com/CasDragon/ModMenu) and [DragonLibrary](https://github.com/CasDragon/DragonLibrary)

***Attention: If you use UMM version 0.32.4, or you are on Linux (or both), you will need to delete your game's 0Harmony file in <Game installation>/Wrath_Data/Managed due to how newer UMM loads libraries. My attempts to manually replace it appear to break things so I've given up on that idea.***

[The currently fixed bugs list is here](https://github.com/CasDragon/DragonFixes/blob/master/DragonFixes/FixList.txt), because I can't be bothered to update my README more than once every 2 years.
